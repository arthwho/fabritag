# Solução para registro de novos lotes:

Quando uma leitura de um lote novo é feita, ele só é adicionado ao sistema e entra na camara sem configuração prévia. Isso faz com que novos lotes sejam adicionados sem nenhum produto no sistema e exige que o usuário acesse a página de Produtos para editar o lote, o que é muito pouco prático e desnecessário.
